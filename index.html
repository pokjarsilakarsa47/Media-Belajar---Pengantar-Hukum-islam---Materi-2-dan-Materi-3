PATCH PERBAIKAN GITHUB Kuis Pengantar Hukum Islam — POK-JAR SILA KARSA TUJUAN Saat pengguna membuka Ringkasan Materi lalu memilih menu lain, Ringkasan Materi otomatis disembunyikan sehingga hanya menu yang dipilih yang tampil. CARA MEMPERBAIKI 1. Buka file HTML utama di repositori GitHub. 2. Klik ikon pensil (Edit this file). 3. Cari bagian event listener menu yang menangani klik menu. Cari teks yang mirip dengan: menuButtons.forEach(...) atau: if(activeSession) ... 4. Di dalam fungsi klik menu, setelah pemeriksaan sesi aktif (activeSession) dan sebelum percabangan menu seperti `if(m==='guide')`, tambahkan baris ini: // Saat pengguna memilih menu lain, sembunyikan ringkasan yang sebelumnya terbuka. if(m!=='review') $('summarySection').style.display='none'; CATATAN - Baris di atas harus berada DI DALAM handler klik menu, setelah variabel `m` berisi menu yang dipilih. - Jangan menambahkan baris tersebut di luar fungsi/event listener. 5. Cari fungsi `returnToMenu()`. Pastikan fungsi itu menyembunyikan Ringkasan Materi. Tambahkan pemeriksaan berikut di awal fungsi, setelah kurung kurawal pembuka: if($('summarySection'))$('summarySection').style.display='none'; Contoh bentuk fungsi: function returnToMenu(){ if(activeSession){ alert('Akhiri kuis yang sedang berjalan sebelum kembali ke menu utama.'); return; } if($('summarySection'))$('summarySection').style.display='none'; mode='home'; // Pertahankan kode asli berikutnya yang mengembalikan tampilan menu utama. } PENTING Contoh fungsi di atas hanya menunjukkan lokasi penambahan. Jangan mengganti seluruh fungsi `returnToMenu()` dengan contoh tersebut karena kode asli setelah `mode='home'` mungkin berisi bagian penting. Tambahkan satu baris penyembunyi ringkasan saja dan pertahankan kode lainnya. 6. Klik “Commit changes” untuk menyimpan perbaikan di GitHub. 7. Uji situs: - Buka Ringkasan Materi. - Klik menu lain. - Pastikan ringkasan tersembunyi dan menu pilihan yang tampil. - Pastikan perpindahan menu tetap terkunci ketika sesi kuis aktif.
